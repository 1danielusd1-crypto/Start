ПРАВКА 2 — ОТДЕЛЬНЫЙ GOOGLE ДЛЯ КАЖДОГО ПРОСТРАНСТВА

1. Для каждого пространства добавлен собственный изолированный Google-контур:
   - свой Google service account;
   - свой зашифрованный JSON-ключ;
   - своя Google Таблица;
   - своя папка Google Drive;
   - свои переключатели выгрузки Sheets/Drive;
   - своя история операций;
   - свой журнал ошибок;
   - свой кэш OAuth-токена.

2. Владелец пространства настраивает Google самостоятельно через /google.
   Доступ к настройке имеют только platform_owner и tenant_owner соответствующего пространства.

3. Добавлены команды:
   /google — состояние и меню Google текущего пространства;
   /google_connect — загрузить/заменить JSON service_account;
   /google_sheet ССЫЛКА_ИЛИ_ID — выбрать таблицу;
   /google_drive ССЫЛКА_ИЛИ_ID — выбрать папку Drive;
   /google_email EMAIL — сохранить email Google владельца пространства.

4. Добавлены отдельные выгрузки:
   - «Залить в Google Sheets»;
   - «Залить файл в Google Drive».

5. Перед каждой выгрузкой проверяется явная привязка исходного чата к пространству.
   Чужой или непривязанный чат нельзя выгрузить через Google другого пространства.

6. Google основного владельца из переменных Render остаётся запасным вариантом только для пространства platform.
   Другие пространства не видят и не используют его аккаунт, таблицу, папку, токены, историю или ошибки.

7. JSON service_account хранится в данных пространства в зашифрованном и аутентифицированном виде.
   Для шифрования требуется стабильный Render Secret:
   TENANT_GOOGLE_MASTER_KEY
   Минимальная длина — 24 символа. Изменение или потеря этого ключа делает ранее сохранённые Google-ключи нечитаемыми.

8. Мастер-ключ Google добавлен в защиту диагностических журналов и memory-forensics.


ПРАВКА 3 — ДИНАМИЧЕСКОЕ ОБЪЕДИНЕНИЕ НАПОМИНАНИЙ

1. В меню напоминалок добавлены независимые для каждого конкретного чата настройки:
   - «Объединять напоминания: ВКЛ/ВЫКЛ»;
   - «Команда /vyapl: ВКЛ/ВЫКЛ».

2. При включённом объединении несколько активных напоминаний одного чата показываются одним сообщением:
   1. Проверить насос
   2. Проверить воду
   3. Проверить давление

3. Интервалы напоминаний больше не заменяются общим интервалом 2 часа.
   Каждая напоминалка сохраняет собственный интервал.
   Общее сообщение обновляется, когда наступает ближайшая отправка любого участника — то есть фактически по самому маленькому текущему интервалу.

4. Когда напоминалка:
   - выполнена;
   - выключена;
   - завершилась по дате;
   - вышла из текущего временного диапазона,
   она удаляется из общего сообщения, а ближайший интервал пересчитывается по оставшимся.

5. Одна напоминалка может быть назначена нескольким чатам. Её расписание продвигается один раз за цикл, а сообщения обновляются отдельно в каждом разрешённом чате.

6. Чат другого пространства блокируется даже при старой ошибочной привязке в настройках напоминалки.

7. Добавлено выполнение:
   /vyapl — если активна одна напоминалка, завершает её; если несколько — показывает кнопки выбора;
   /vyapl_123 — завершает конкретную напоминалку №123;
   /vyapl_history — история выполнений пространства.

8. Для каждого выполнения сохраняется:
   - ID события;
   - дата и время;
   - пространство;
   - ID и текст напоминалки;
   - чат и название чата;
   - ID пользователя;
   - имя/username пользователя.

9. Повторное выполнение завершённой напоминалки не создаёт новую запись.

10. Старое состояние экспериментальных групп v142 удаляется при первом цикле v149, а старое объединённое сообщение удаляется из чата.
    Если старая функция уже успела физически изменить интервалы напоминаний на 120 минут, исходные интервалы восстановить автоматически невозможно — их нужно один раз выставить вручную.
