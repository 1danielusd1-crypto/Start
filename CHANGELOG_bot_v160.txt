bot_v160_window_button_annotations

1. Удалено обычное окно Ф232 «Операция выполняется» для telegram_update и других не-файловых операций. Ф233 для скачиваний/экспортов оставлен.
2. Отключён ошибочный 120-секундный v153 UI-cache результатов edit_message_text/edit_message_reply_markup — основная причина повторно «неработающих» кнопок.
3. Для callback UI-thread отключена лишняя задержка repaint; фоновые обновления сохраняют штатный throttle.
4. «Назад» теперь снимает снимок истории только после подтверждённого Telegram edit; при потерянной истории возвращает на главное окно вместо молчаливого handled.
5. «Назад осн. окно» редактирует именно нажатое окно и больше не удаляет другое параллельное главное окно.
6. Реестр окон сохраняет параллельные main/remaining/stored окна; старое окно не объявляется невалидным только из-за появления нового.
7. Усилено автоудаление временных сообщений: до 3 попыток. «Новая копия в очередь не добавлена» больше не подменяет Ф91.
8. Добавлены отсутствовавшие константы маркеров для reminder merge/command/history.
9. В каждое маркированное окно автоматически добавляются /iz-mr и /tz. Уникальный token фиксирует конкретное логическое окно, callback происхождения, chat/message, тип/код/day/params. При обычной навигации token новый; toggle сохраняет token.
10. /iz-mr <marker> <token> <имя> сохраняет постоянное имя/описание окна. /tz <marker> <token> <ТЗ> сохраняет ТЗ с контекстом окна.
11. В меню журналов добавлены «🏷 Скачать маркировки» и «📝 Скачать ТЗ окон». Файловая выгрузка использует оставленный Ф233.
12. Restore validator принимает v160 snapshots.
