База: полный bot_v168_clean_core_record_identity.

ИЗМЕНЕНИЯ

1. Основное окно Ф91
- Для владельца добавлена отдельная кнопка «📝 Скачать ТЗ окон».
- Использует уже существующий экспорт v160:export_tz; формат ТЗ и архивная логика не дублируются.

2. 💰Перес — режим «кнопка/слеш» применяется сразу к новой копии
- Режим «кнопка» продолжает прикреплять кнопку «✏️ Изменить» непосредственно при Telegram copy_message.
- Для режима «слеш» восстановлена безопасная отправка текстовой финансовой копии сразу с /izm_R..._u... или /izm_U..._u....
- UID для такой копии вычисляется детерминированно по source chat/message + destination chat и затем присваивается реально созданной финансовой записи.
- R/U позиция предсказывается под RLock целевого финансового чата, который удерживается до создания записи; это не даёт соседней финансовой операции занять предсказанный номер между отправкой копии и созданием строки.
- После создания строки команда сверяется с фактической. Если из-за исторической хронологии номер всё же отличается, остаётся одноразовая корректировка UI.
- v168 immutable record_uid сохранён: редактирование привязано к UID, а R/U остаётся отображаемым номером.

3. Напоминалки — тройной переключатель «Объединять»
Цикл:
  ВЫКЛ -> ВКЛ -> 1 СООБЩЕНИЕ -> ВЫКЛ

- ВЫКЛ: каждая напоминалка отправляется отдельно.
- ВКЛ: сохранено прежнее v149 поведение объединения нескольких активных напоминалок.
- 1 СООБЩЕНИЕ: все активные тексты данного чата всегда находятся в одном общем Telegram-сообщении, даже если активна только одна напоминалка.
- Индивидуальные интервалы напоминалок сохраняются.
- Старый boolean merge_enabled автоматически мигрирует в новую tri-state настройку и остаётся compatibility mirror.

4. INFO -> «☁️ Google Чт–Ср»
Добавлено новое окно Ф240⏰ для управления rolling Google Sheet четверг-среда.
Период самого листа остаётся строго Чт-Ср; при новом четверге создаётся новый tab, внутри периода обновляется тот же tab.

Режимы обновления:
- ✋ Только вручную
- ⚡ После финансовых изменений (debounce 8 секунд)
- 🕒 Каждые 15 минут
- 🕐 Каждый час
- 🌙 Ежедневно 00:01
- 🌅 Ежедневно 05:01
- отдельная кнопка «☁️ Обновить Чт–Ср сейчас»

- Старые F47 кнопки 00:01/05:01/авто остаются совместимыми.
- Google update jobs в нормальном runtime отправляются в существующий EXPORT_TASK_POOL, а не создают отдельный raw worker-поток на каждый чат.
- Старые v167/v168 enabled/time настройки автоматически мигрируют без изменения выбранного ежедневного времени.

5. Restore/version compatibility
- validator расширен на bot_v169_* для собственных v169 snapshots/restores.
