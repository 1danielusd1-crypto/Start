1. Excel formulas restored
- ARS and USD simple tables again contain real formulas for income, expense, closing balance and turnover.

2. Expense article columns are stable
- Excel article tables always include the complete configured expense article list, including articles with zero transactions in the selected period.
- Used custom articles are appended if they are not present in the configured order.

- Legacy internal callback token `wedthu` is retained so old buttons remain compatible.
- `wedthu` now means the complete Thursday-through-Wednesday 7-day period.
- For 2026-08-08 the period is 2026-08-06 through 2026-08-12.

5. Rolling Google Sheet Thu-Wed
- F47 contains Google Thu-Wed schedule controls.
- Selectable daily update time: 00:01 or 05:01.
- Current owner schedule defaults to enabled at 05:01.
- A fixed period tab is created/updated, e.g. 06-12.08.26.
- During the same period the same tab is overwritten/refreshed daily.
- On the first Thursday of the next period a new tab name is generated automatically.
- Render sleep/restart is handled with catch-up: if the exact minute was missed, the first READY after the selected time performs that day’s update once.
- Added “Обновить лист Чт–Ср сейчас”.
- Google rolling tab uses formulas, fixed column widths, clipped Description text, borders and #,##0 number formatting.
