УСТАНОВКА ПОЛНОГО ПАКЕТА
1. Сохраните резервную копию текущего состояния и исходников v147.
2. Распакуйте bot_v148_FULL_PACKAGE_FLAT.zip в корень проекта без дополнительной папки.
3. В корне должны лежать bot.py, все пронумерованные модули, modules_manifest.json и файл 93_v148_multitenant_spaces.py.
4. Не смешивайте модули от других версий. bot.py проверяет SHA-256 до запуска Telegram/MEGA.
5. Для запуска единым файлом можно использовать FULL_bot_v148_multitenant_spaces.py.

УСТАНОВКА CHANGED-FILES-ONLY ПОВЕРХ v147
Замените/добавьте в корне проекта все файлы из bot_v148_CHANGED_FILES_ONLY.zip:
- bot.py
- modules_manifest.json
- 00_core.py
- 10_mega_runtime.py
- 40_message_router.py
- 80_callback_router.py
- 90_commands_exports.py
- 91_finance_records_handlers.py
- 93_v148_multitenant_spaces.py

Остальные модули должны остаться именно из полного комплекта v147 diagnostic hardening.
Файл 92_v147_diagnostic_hardening.py НЕ удалять: v148 загружает его перед новым модулем 93.
При сомнении используйте полный ZIP, а не пакет только изменённых файлов.

ПЕРВЫЙ ЗАПУСК
- v148 создаст «Основное пространство владельца».
- Существующие обычные чаты v147 останутся в нём.
- Старые additional owners будут перенесены в отдельные пространства.
- Старые перекрёстные пересылки между пространствами будут удалены.

БЫСТРЫЙ СТАРТ
/space — открыть пространство.
/space_chat_link — получить ссылку и код подключения чата.
/space_join КОД — применить код в другом чате, где бот уже состоит.
/space_user_link operator — пригласить оператора.
/space_user_link viewer — пригласить пользователя только для просмотра.
/space_users — посмотреть роли.
/space_chats — посмотреть подключённые чаты.

КАК ОТДЕЛИТЬ СУЩЕСТВУЮЩИЙ ЧАТ v147
1. Основной владелец открывает нужный чат и выполняет /space_unlink.
2. Администратор этого чата выполняет /space_claim Название пространства.
3. После этого чат получает собственные настройки, пользователей, напоминания и связи.

КАК ПОДКЛЮЧИТЬ ПОДЧАТ
1. В корневом чате пространства выполнить /space_chat_link.
2. Добавить бота в целевой чат по Telegram-ссылке либо скопировать код.
3. Администратор целевого чата выполняет /space_join КОД.

После деплоя проверьте в тестовых чатах:
- /space в двух разных пространствах;
- изменение одной настройки INFO;
- добавление записи ARS/USD;
- напоминалку;
- пересылку только между чатами одного пространства;
- отсутствие чужих чатов в списках.
