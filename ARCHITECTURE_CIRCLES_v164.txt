МОДЕЛЬ v164

Круг 0 — владелец бота
  OWNER_ID
  tenant = platform
  Никакие другие Telegram-чаты сюда не добавляются.

Круг 1 — прямое подключение
  Бота нашли/добавили напрямую -> собственный tenant этого чата.
  Это корень своей семьи.

Круг 2 — подключение по ссылке круга 1
  Чат получает собственный tenant.
  В metadata хранится parent_first_chat_id.
  Данные не переносятся в tenant родителя и не попадают в platform.

Пример:
  OWNER_ID                         [platform tenant]

  Chat A — 1-й круг                [tenant A]
    ├─ Chat A1 — 2-й круг          [tenant A1, parent=A]
    └─ Chat A2 — 2-й круг          [tenant A2, parent=A]

  Chat B — 1-й круг                [tenant B]
    └─ Chat B1 — 2-й круг          [tenant B1, parent=B]

Все пять tenants физически раздельные. Иерархия нужна для отображения, прав управления и разрешённых связей, а не для смешивания данных.
