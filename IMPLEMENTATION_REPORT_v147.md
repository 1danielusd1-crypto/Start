# Реализация v147_multitenant_audit_restore

База: v146_window_epoch_lazy_refresh_durable.

## Основные изменения

- Добавлен базовый реестр пространств `tenant`, изоляция чатов и контурные профили Google.
- В f206 добавлено меню «Права чатов» с отдельными переключателями функций.
- Добавлены `/json_full` и безопасное подтверждаемое `/restore` для полного владельца и контурного владельца.
- Корневой путь MEGA переведён на `/TelegramBotBackupsStart`.
- Добавлена рекурсивная маскировка секретов до записи диагностических событий; `mega-login` журналируется без логина и пароля.
- Исправлен шаблон «Гомонковых»: пример не участвует в вычислениях, добавлена кнопка изменения.
- Исправлено объединение напоминаний: интервал группы определяется минимальным активным интервалом и больше не перезаписывает интервалы отдельных задач.
- Добавлен `/vyapl_ID` и защита от повторного выполнения одного срабатывания.
- В f191 выводятся целевые чаты; лишняя навигация заменена на «К напоминалкам».
- В USD-режиме «За месяц» сохраняет клавиатуру текущего окна.
- Добавлено уведомление о занятом экспорте с последующим сообщением о доступности.
- Добавлен аудит кнопок/slash-команд и реестр состояний чатов.
- Excel-итоги дополнены строками «Гомонковые» и «Остаток в обороте» для простых таблиц.

## Проверки

- `python -m py_compile` — успешно для всех файлов v147 и FULL-файла.
- Проверка manifest SHA-256 — успешно.
- Проверка первой и последней строки по manifest — успешно.
- Старый литерал `"/TelegramBotBackups"` — не найден.
- Маскирование `mega-login` — подтверждено статической проверкой.

## Важное ограничение проверки

Полный runtime-запуск в текущей среде не выполнен, потому что здесь отсутствует пакет `telebot` (`pyTelegramBotAPI`). Синтаксис, структура пакета, manifest и статические проверки пройдены.
