# v175 — лёгкий режим для проверки скорости

Открой: **INFO → 🧱 Тяжёлые процессы**.

## Полный режим
`🧱 Тяжёлые процессы: ВКЛ`

Обычная работа бота со всей диагностикой, Google-автоматикой, full backup и watcher.

## Лёгкий тестовый режим
`⚡ Тяжёлые процессы: ВЫКЛ`

Основная бизнес-логика остаётся включённой:
- финансы;
- пересылка;
- напоминалки;
- задачи;
- SECRET;
- SQLite + compact MEGA delta.

Останавливается фоновая нагрузка, которая не нужна для самого выполнения этих функций.

### Как тестировать
1. До переключения 10–15 раз открыть/закрыть INFO, фин. меню, напоминалки и задачи и оценить задержку.
2. Нажать `Тяжёлые процессы: ВЫКЛ`.
3. Подождать 10–20 секунд: уже запущенная фоновая операция может закончиться один раз.
4. Повторить те же кнопки.
5. Если отклик заметно улучшился — причина находится в отключённом фоновом контуре, и его можно оптимизировать по одному блоку.
6. Если разницы почти нет — следующим этапом надо профилировать сам путь callback → render text/keyboard → edit_message_text, а не MEGA/Google/диагностику.

Переключатель глобальный и доступен только основному владельцу.
