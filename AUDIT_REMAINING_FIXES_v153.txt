ПОДТВЕРЖДЁННЫЕ ПРОБЛЕМЫ v146
1. Runtime diagnostics: failed=3 при наличии более длинного failed_details. Причина — разные моменты обновления счётчика и кэша деталей.
2. Несколько финансовых задач имели missing reminder_edit, хотя сообщение не было операцией редактирования напоминалки.
3. Runtime export включал большое количество candidate_runtime_latest_* и файлы разных эпох без ясной границы.
4. Window diagnostics: message is not modified, duplicate marker candidates, edit target missing, keyboard edit failed и delete failed.
5. Очереди имели большие исторические max_wait: recovery около 20 с, delayed около 34 с, backup более 60 с.
6. В снимках присутствовали одновременно разные Render instance; предыдущая причина завершения определялась слишком грубо.
7. В раннем журнале аргументы mega-login содержали реальные credentials.
8. История жизненного цикла чатов не входила в runtime ZIP.
