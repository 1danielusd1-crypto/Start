УСТАНОВКА BOT V152

Вариант 1 — полный ZIP
1. Удалите старые файлы бота из корня Render.
2. Загрузите все файлы из bot_v152_FULL_PACKAGE_FLAT.zip.
3. Не смешивайте модули разных комплектов.
4. Запустите deploy.

Вариант 2 — changed-only поверх полного v151
1. Оставьте все модули полного v151.
2. Замените bot.py и modules_manifest.json.
3. Добавьте 102_v152_human_journals_chat_rights.py.
4. Выполните deploy.

ОТКРЫТИЕ ПРАВ
INFO → 🛡 Защита → 🛡 Права чатов.

Основной владелец видит все чаты всех пространств и глобальные ограничения платформы. Владелец/администратор пространства видит только чаты своего пространства.

ВАЖНО
По умолчанию все старые чаты наследуют разрешённые функции пространства. Ничего вручную включать после обновления не требуется.
