bot v154 — Excel USD isolation / date expense marks

1. Ф111 и Ф114
- Даты с реальным расходом отмечаются как 📝N.
- Доход без расхода метку не получает.
- Маркер не меняет callback и не влияет на выбор диапазона.

2. ARS / USD Excel
- USD экспорт больше не читает usd_amount из ARS-записей.
- USD строится только из отдельного долларового реестра records/usd_records.
- ARS и USD остатки, приход, расход и гомонковые считаются независимо.
- Во всех Excel/Google вариантах USD-блок идёт после ARS через ровно две пустые строки.
- В Excel статей категории остаются только у ARS.
- USD всегда имеет формат: Дата | Описание | Приход | Расход, затем обычные USD-итоги.

3. Ф179
- Добавлен переключатель «💵 USD расходы в таблице: ВКЛ/ВЫКЛ».
- Настройка хранится отдельно для каждого чата.
- ВЫКЛ полностью убирает USD-блок из Excel/Google экспорта.
- По умолчанию для существующих чатов ВКЛ.

4. Совместимость
- /restore принимает полные snapshots v153 и v154.
