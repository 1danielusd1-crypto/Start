v140 — iPhone-отметка расхода, описание чатов, маркеры окон и универсальный «Назад»

1. Добавлена функция «📱 Быстрый расход iPhone» в меню «Инфо».
   - выбор чата назначения;
   - секретная HTTPS-ссылка для приложения «Команды»;
   - тестовая отправка;
   - смена секретной ссылки;
   - событие сначала сохраняется, а затем отправляется; после временной ошибки Telegram/deploy доставка повторяется.

2. Усилен контроль маркеров окон.
   - журнал пишет исходный callback, нормализованный ключ, chat/message ID, назначение окна, первую строку текста, ключ клавиатуры и рекомендуемый следующий номер маркера.

3. В Ф52 и Ф53 добавлено «ℹ️ Описание чатов».
   - ID, тип, название, username, описание, количество участников, администраторы, Telegram Premium/обычный для доступных User-объектов;
   - накопленный список пользователей, которых бот реально видел;
   - длинные карточки разбиваются на страницы.
   - Telegram Bot API не выдаёт полный произвольный список всех участников, поэтому бот показывает точное количество, администраторов и известных ему пользователей.

4. В окна без собственной кнопки возврата добавляется универсальная «🔙 Назад», возвращающая предыдущее меню в рамках текущего процесса. Основная кнопка возврата сохраняется.

5. Все изменения применены для владельца и разрешённых интерфейсов; секретная ссылка доступна только владельцу.
